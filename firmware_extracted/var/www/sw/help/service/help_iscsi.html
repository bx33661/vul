iSCSI

 

Detta gör det möjligt för användaren att använd Blue-ray/DVD-enheten för LG Network Storage som en CD-enhet. LG Network Storages iSCSI-tjänst tillåter inloggning och användning av flera användare.

 

[iSCSI Initiator Installation]                                         

För att kunna använda iSCSI, måste Initiator-programmet vara installerat på datorn

A. Installation av Initiator på en Windows-dator  

För Windows XP, ladda ner installationsprogrammet från Microsoft-hemsidan nedan  

☞ Hemsida  

http://www.microsoft.com/downloads/details. aspx?familyid=12cb3c1a-15d6-4585-b385-befd1319f825&displaylang=en För Windows Vista inkluderas redan ett program i operativsystemet och ingen ytterligare installation krävs.

B. Installation av Initiator på en Linux-dator

För Linux kan Initiator installeras automatiskt från hemsidan. För ubuntu Linux, skriv  

$ sudo apt-get install open-iscsi

och för fedora, skriv

$ yum install open-iscsi

för att installera Initiator automatiskt

☞ Hemsida http://www.open-iscsi.org/

C. Installation av Initiator på en Mac  

Installera globalsan iSCSI initiator. Det kan laddas ner från hemsidan "studio network solutions".

[Serversynkronisering]

[iSCSI-anslutning]

A. Anslutning för en Windows-PC  

① Aktivera iSCSI initiator. För Windows Vista, gå till “Kontrollpanelen → iSCSI Initiator” och aktivera Initiator. För Windows XP, gå till Startmenyn och välj iSCSI Initiator från programlistan. Om en obligatorisk certifieringsprocedur (CHAP) har ställts in i webbinställningen, ange den information som krävs under fliken Allmänt genom att trycka på Secret-knappen.  

② Att hitta iSCSI-destinationen (LG-NAS). Klicka på fliken Discover längst upp i iSCSI Initiator-programmet. Klicka sedan på knappen "Lägg till" längst ner. Nu bör ett nytt fönster för Lägg till destinationsportal (bild nedan) visas. Ange destinationens IP-adress (LG Network Storage). Om en obligatorisk certifieringsprocedur (CHAP) har ställts in i webbinställningen, ange den information som krävs genom att trycka på knappen Avancerat i fönstret ovan.

③ Logga in. Gå till fliken Destinationer längst upp i iSCSI Initiator-programmet. Om alla ovanstående procedurer har genomförts korrekt, kommer iSCSI Initiator att hitta och skapa en lista för informationen för destinationen (LG-NAS). Välj relevant destinationsnamn och tryck på "Logga in. . .” och klicka på "OK" i popup-fönstret.

④ Kontrollera att destinationen har anslutits enligt följande. Destinationen kan inspekteras genom att gå till Enhetsadministratör → DVD/CD-ROM-enhet.  

⑤ NAS inbyggda ODD kan nås via användning av verktyg som exempelvis CyberLink Power2Go.  

⑥ Logga ut när du är färdig. Gå till fliken Destinationer längst upp i iSCSI Initiator-programmet. Klicka sedan på knappen Detaljer längst ner.

Välj relevant Destinationsnamn och klicka på "Log Off. . . “

※ På grund av kompatibilitetsproblem mellan iSCSI Initiator och Windows Vista, är det möjligt att Windows Vistas inbyggda ODD-lagringsfunktioner, mastered eller live file system, inte är tillgängliga.  

B. Anslutning för en Linux-PC  

① Aktivera iSCSI initiator. $ /etc/init.d/open-iscsi start

② Hitta iSCSI-destinationen. Om IP-adressen för LG NAS (destination) är 192.168.10.2, är destinationen:  

 

$ iscsiadm -m discovery -t sendtargets -p 192.168.10.2

 

Så snart som destinationen har hittats, verkställ ovanstående kommando, som kommer att visa destinationsnamnet. Följande är ett exempel:

 

$ 192.168.10.2:3260,1 iqn.2009-01.com.lge:LG-NAS.123456

 

③ Log in. Inloggningskommando för ovanstående destination är:  $ iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 --login

 

④ Bekräfta anslutningen till destinationen genom att använda nedanstående kommando. $ cdrecord -scanbus

⑤ ODD-verktyg som exempelvis cdrecord kan användas för att utnyttja NAS inbyggda ODD.  

  • Hemsida  
  • http://cdrecord.berlios.de/private/cdrecord.html

①     Logga ut när du är färdig. Använd följande kommando:  

 

$ iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 –logout

 

 [Anslutning för CHAP-certifiering]

 

①  Open Öppna open-iscsi set-up-filen “/etc/iscsi/iscsid.conf” och ställ in CHAP-certifieringen. Följ nedanstående instruktioner. (Lösenordet för CHAP-certifieringen måste överensstämma med lösenordet som är inställt för iSCSI-tjänsten på hemsidan för LG Network Storage.  
discovery.sendtargets.auth.authmethod = CHAP discovery.sendtargets.auth.username = inAdmin discovery.sendtargets.auth.password = password set up (Target Secret)
node.session.auth.authmethod = CHAP node.session.auth.username = outAdmin node.session.auth.password = password set up (Initiator Secret)

② Aktivera open-iscsi. $ /etc/init.d/open-iscsi Om open-iscsi redan var aktiverat, starta om. $ /etc/init.d/open-iscsi restart

③ Återstående procedurer är samma som för [Anslutning för en Linux-PC].

C. Anslutning för en Mac

① Aktivera iSCSI initiator. Gå till Systeminställningar -> globalSAN iSCSI  

② Hitta iSCSI-destinationen. Om IP-adressen är 192.168.10.2, se nedan. Gå till globalSAN iSCSI -> Portaler och tryck på “+” och skriv in 192.168.10.2 och tryck på “OK”.  

Om en obligatorisk certifieringsprocedur (CHAP) har ställts in i webbinställningen, ange den information som krävs genom att trycka på knappen Avancerat i fönstret ovan.

③ Logga in. Gå till globalSAN iSCSI -> Destinationer, välj relevant destinationsnamn och klicka på “Logga in. . . .” och klicka sedan på "Anslut" i popup-fönstret.

④ Kontrollera att destinationen har anslutits enligt följande. Gå till Tillägg -> Systemprofiler och kontrollera att “iSCSI” visas under “Diskbränning” Interconnect.  

Verktyg som exempelvis Disc Utility/Finder kan användas för att utnyttja NAS inbyggda ODD.

⑤ Logga ut när du är färdig. Gå till globalSAN iSCSI -> Destinationer, välj relevant destinationsnamn och klicka på “Logga ut. . . .” och klicka sedan på "Koppla från" i popup-fönstret.  

* Kommentarer Eftersom nätverksanslutningen för LG Network Storage Blue-ray drive, gör det möjligt för alla inloggade användare att använda programmet, är det viktigt att andra användares arbete inte avbryts. Exempelvis, i händelse av att andra användare håller på att bränna data på Blue-ray-enheten, rekommenderas det att undvika kommandon som kan störa denna procedur, som exempelvis "öppna enhetsfack". Om bränning/läsning av data pågår på LG Network Storage via nätverksenhetsanslutningen, kan det pågå betydande dataöverföringar inom nätverket, vilket kan leda till problem för dataöverföringar via iSCSI, med långsammare och begränsad skriv-/läshastighet per skiva som resultat.
