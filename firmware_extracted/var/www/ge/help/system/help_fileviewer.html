File Viewer

Von entfernten Orten aus kann man sich durch das Internet mit dem LG NAS verbinden und nach auf dem LG NAS gespeicherte Dateien suchen um sie dann zu öffnen oder abzuspeichern, außerdem kann man von entfernten Orten Dateien auf das LG NAS hochladen.

<Öffnen>

① Im oberen Menü den File Viewer anklicken.

② Benutzerkennung und Passwort eingeben. Benutzerkennung und Passwort sind mit denen, die Sie beim Öffnen von Netzwerkordnern benötigen, identisch.

③ Das folgende Web-Fenster öffnet sich. Hier erscheinen die gleichen Fenster wie wenn Sie sich mit einem Netzwerkordner verbinden.

④ Wenn Sie den Ordner auswählen durch den Sie navigieren wollen wird der Inhalt angezeigt.

⑤ Wenn Sie eine Datei anklicken erscheint ein Bildschirm mit der Frage ob Sie die entsprechende Datei Speichern oder Öffnen wollen.

⑥ Mithilfe der Upload-Funktion können Sie Dateien vom PC auf das LG NAS hochladen und dort speichern.

* Datentransfers werden nur in Dateieinheiten durchgeführt und sind beim Upload auf 200MB begrenzt.
