WebDAV

 

Le LG NAS supporte la fonction WebDav qui permet de glisser-lâcher/ ouvrir/ sauvegarder les fichiers à distance après connexion à distance via le web sur le LG NAS. (Réservé aux 'Fichiers MS Office')

 

* Lorsque vous utilisez la fonction WebDav, vous pouvez utiliser les fichiers du LG Network Storage comme ceux dans le PC d’utilisateur en vous connectant sur la page web.

 

Pour utiliser le WebDav, il faut que Microsoft MS Office soit installé sur le PC.

 

[Paramétrer]

Pour utiliser le WebDav, il faut générer le dossier d’utilisateur et sélectionner le WebDav parmi les protocoles supportées

 

[Ouvrir]

(1) Sélectionnez l’icône WebDav qui se trouve en haut

 

(2) Passez la certification d’utilisateur. Cette étape est identique à celle de connexion au dossier réseau.

 

(3) L’écran comme ci-dessous s’affiche losque vous avez passé la certification. Vous pouvez alors glisser-lâcher/ éditer-sauvegarder/ ouvrir directement des fichiers.

 

*Ici la référence est Windows XP. Référez-vous au site internet pour les autres systèmes d'exploitation.
