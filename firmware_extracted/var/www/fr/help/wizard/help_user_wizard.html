Il'y a un assistant LG NAS de creér utilisateur.

  • ① Cliquez sur le bouton “Enregistrer l'Utilisateur”.
  • ② Entrez l'identification de l'utilisateur, le nom, le mot de passe, la decription et l'email adresse désirés, puis cliquez sur le bouton de’Sauvegarder’
  • ③ Cliquez sur le bouton des ‘Editer Groupe’ pour installer des Groupes d'utilisateurs enregistré ; Cliquez sur le bouton ‘Editer Dossiers’ pour installer l'autorisation d'accès de dossier. Ceci liera l'utilisateur aux pages respectives.
