Energía

Usted puede ajustar todos los ajustes relacionados con la energía para que haya el LG Network Storage (Hibernación, UPS y sistema de cierre)

Configuración del modo de hibernación

Esto permite a todos los discos duros del LG Network Storage reducir al mínimo el consumo de energía después de un cierto período sin ningún transferencia de datos. La lectura o escritura de datos del LG Network Storage durante el modo de hibernación reactivará gradualmente el LG Network Storage y será totalmente reactivado a los 3-15 segundos.

* Si no usa el NAS por un largo tiempo o frecuentemente por corto tiempo, es recomendado usar el modo de hibernación.

① Para configurar la función de hibernación, haga clic en el botón ‘Editar’.

② Seleccione “Activar” para seleccionar el modo de hibernación, o “Desactivar” para desactivar. Al seleccionar el ` Permitido ‘, proceda al paso siguiente.

③ Tiempo de espera determinado.

④ Si no hay tráfico de datos durante el tiempo dado dentro del LG Network Storage, entrará en modo de la hibernación. La hora se puede fijar a 10/30/60/120 de los minutos.

⑤ Cliqueehasque encendido el botón de ‘Aplicar’ del `para dictar cambios al LG Network Storage. Cliqueehasque encendido el botón de ‘Cancelar’ del `para desechar cambios.

Configuración de la energía de UPS

Un UPS externo es eficaz para las paradas repentinas de la energía. Al conectar un UPS externo con el LG Network Storage, confirme las acciones de la UPS.

① Cliquee encendido el botón de ‘Editar’ del `para configurar el UPS.

② Compruebe el `ENABLE (Permitir)’ para activar el UPS, o el `DISABLE (No permitir)’ para desactivar. Al seleccionar el `Enable’, proceda al paso siguiente.

* LG Network Storage supporta APC solo Style USB UPS.

③ Decida si cerrar LG Network Storage después de intervalo de tiempo señalado o cuando la energía de la UPS llega a ser baja en caso del corte de energía externo inesperado.

* Al fijarlo para cerrar dependiendo de la energía restante de LG Network Storage, el intervalo de tiempo puede diferenciar a partir de un tipo del UPS a otro.

④ Decida si desconectar el UPS o no después de que el intervalo de tiempo es designado o cuando el LG Network Storage cerró debido al corte de energía inesperado.

* Si otro dispositivo está conectado con el UPS, por favor no apague el UPS. Al contrario, mantengalo encendido..

⑤ Cliquee encendido el botón de ‘Aplicar’ `para incorporar cambios al LG Network Storage. Cliquee encendido el botón de ‘Cancelar’ `para desechar cambios.

Encender / apagar el modo de ahorro máximo de energía

LG Network Storage puede cortar la energía del HDD durante un cierto tiempo cuando el usuario no haga uso del programa, ejecutando LG Network Storage con un mínimo uso de energía. Cualquier intervalo de tiempo durante el día puede ser configurado para el modo de ahorro máximo de energía. Cabe señalar aunque el modo de ahorro máximo de energía esté a punto de empezar en un momento determinado, puede ser terminado por cualquier trabajo en acción.

* Cuando la red se utiliza para transferir datos o la BD / DVD está siendo utilizado, el modo de ahorro máximo de energía no se iniciará.

① Para una nueva configuración, pulse el botón “editar”.

② Seleccione “Aplicar” para activar o “cancelar” para desactivar.

③ Para seleccionar “aplicar”, seleccione “aplicar” en la ventana de calendario del programa y seleccione el comienzo y término del modo de ahorro máximo de energía. El comienzo del modo de ahorro máximo de energía debe tener al menos 5 minutos de brecha con la hora actual. Por ejemplo, si la hora actual es 12:00, el modo de ahorro máximo de energía debe ser fijado a partir de 12:05.

④ Para guardar la configuración actual, presione “Aplicar”.

⑤ Una vez que llegue al comienzo del tiempo establecido, el sistema automáticamente se entrará al modo de ahorro máximo de energía y en la pantalla aparecerá un mensaje, “Funcionando Ahora . . . “.

⑥ Una vez que el sistema está plenamente en el modo de ahorro máximo de energía, aparecerá el siguiente mensaje en la pantalla LCD. En esta etapa, ya no es posible conectar la unidad de red y usar las diversas funciones que ofrece LG Network Storage.

♣ El modo de ahorro máximo de energía también se puede acceder a través del botón en la parte delantera.

Cierre

No vaya directamente al LG Network Storage, como el LG Network Storage se puede comenzar y parar vía web.

① Reiniciar

- Termina todas las operaciones actuales y reinicia el LG Network Storage.

- Una advertencia aparecerá cuando cliquea el botón, y el sistema puede ser reiniciado cliqueando en el botón de `OK’.

- Durante reeinicio, el acceso de Internet no está disponible.

② Apagar

- Termina todos los procesos actuales y cierra el LG Network Storage.

- Una advertencia aparecerá cuando cliquea el botón, y el sistema puede ser reiniciado cliqueando en el botón de ‘OK’.

- Durante reinicio el acceso de Internet no está disponible.

Activar el sistema de forma remota

Si el LG Network Storage ha entrado en su modo de ahorro máximo de energía, puede ser activado de forma remota a través del acceso al internet. La pantalla de acceso a través de Internet es un poco diferente de la pantalla de inicio en el modo normal, y sólo el administrador puede utilizar la contraseña para activar el sistema. La sincronización puede tardar aproximadamente un minuto.

* En el modo de hibernación, solamente se puede acceder por ‘http’.

Si la contraseña del administrador introducido es correcta, el sistema se sincronizará automáticamente.
