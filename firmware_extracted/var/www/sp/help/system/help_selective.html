Selective Mirror

(Protección de datos selectivos en carpetas)

Si usa la función ‘Selective Mirror’, se crea una duplicación de la carpeta seleccionada para casos de perdida de datos.

Agragar lista de ‘Selective Mirror’

① Active la función ‘Selective Mirror’.

② Si presiona ‘Agregar’ aparecerá una pantalla para aregar una nueva lista.

③ En ‘ruta de origen’ seleccione la carpeta para duplicar y en ‘ruta de destino’ seleccione la carpeta para guardar la copia de seguridad.

④ Presione ‘Guardar’ y se creará una nueva lista de ‘Selective Mirror’.

Editar la lista de ‘Selective Mirror’

① Chequee en el tema que desee editar y pulse el botón ‘Editar’.

* Sólo un tema se puede editar a la vez.

② Edite la “ruta de origen” y la “ruta de destino” y pulse “Aceptar” para confirmar.

Eliminar la lista de ‘Selective Mirror’

① Chequee en el tema que desee eliminar.

* Se pueden eliminar más de un tema al mismo tiempo.

② Pulse el botón “eliminar” para confirmar.

Usar ‘Selective Mirror’

Si FTB y SMB fue utilizado para almacenar datos en LG Network Storage y un cambio incurre en la carpeta de origen, el mismo cambio se aplicará a la carpeta de destino y la carpeta de origen será doble protegido.

* Para maximizar los efectos de ‘Selective Mirror’, se recomienda la creación de diferentes volúmenes de la carpeta de origen y la carpeta de destino.

E.g.) carpeta de origen volume1 / source carpeta de destino volume2 / destination

* Condiciones

① La carpeta de origen y la carpeta de destino no puede ser la misma carpeta.

② Una fuente de la carpeta de origen puede tener hasta 4 carpetas de destino.

③ Una carpeta designada como una carpeta de origen no puede ser designada como una carpeta de destino en otro lugar.

④ Una subcarpeta de una carpeta de origen no puede ser designada una carpeta de destino.

⑤ Una carpeta designada como una carpeta de destino no puede ser designado como una carpeta de origen en otro ambiente.
