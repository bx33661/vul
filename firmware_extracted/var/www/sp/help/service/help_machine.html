Time Machine

 

El servicio de máquina de tiempo es una función de copia de seguridad automática interna de Mac OS X. Es un servicio que mantiene la copia de los datos de Mac como un estado actualizado en el LG Network Storage.

 

※ Este servicio es compatible con Mac OS X versión 10.5 Leopard o posterior.

 

[Configuración de web]

① Asigne una carpeta para guardar la copia de datos de Mac. Asigne AFP(Mac) como protocolo de soporte de la configuración de carpetas.

② Configure una máquina de tiempo como ‘usar’ y seleccione la carpeta asignada.

③ Pulse el botón ‘aplicar’.

※ Si el servidor AFP no es está activo en la web, se activa automáticamente durante la configuración de la máquina de tiempo en Mac.

 

[Mac OS]

① Pulse “configuración de entorno del sistema” > “Máquina de tiempo”

② Pulse “cambio de disco…” y seleccione una configuración de carpeta en la web, y pulse “usar como configuración”.

③ Cuando se muestre la ventana emergente de registro, introduzca la ID y la contraseña y pulse ‘conectar’.

④ Desde entonces, la máquina de tiempo se activa automáticamente y se inicia la copia de seguridad.

※ Si se pulsa el botón “opción”, puede configurar una carpeta no necesaria para la copia de seguridad.
