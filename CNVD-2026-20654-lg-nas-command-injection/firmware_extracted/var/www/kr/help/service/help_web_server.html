Web Server

 

Web Server 기능은 NAS에 사용자의 Homepage 를 작성할 수 있도록 해주는 기능입니다.

 

Web Server  ‘사용함’ 으로 설정하면 NAS 상에 myweb 폴더가 생성되며 사용자는 Web 에 게시하고자 하는 내용을 SAMBA 를 통하여 Upload 가능합니다.

FTP 를 사용하여 Upload 하고자 하는 경우 Folder 메뉴에서 myweb 폴더에 대하여 FTP 기능을 활성화 하는것이 가능합니다.

 

사용자 Web 을 위한 Web Port 는 기본적으로 80 으로 되어 있습니다. 임의의 포트를 사용하고자 할때 10000~50000 사이의 포트에서 임의의 포트 지정이 가능합니다

 

SSL : https (보안연결)을 활성화 하여 사용자의 Web 게시를 하는것도 가능합니다.

 

SSL Port : 보안 접속을 위해 사용 할 Port 를 지정 할 수 있습니다.

 

주의 : 일반 Web port 와 SSL Port 는 중복되어 사용할 수 없습니다.   

       NAS 의 설정 변경을 위한 Web page 는 http://server_ip:8000/ 에서 설정 할 수 있습니다.

 

 

MySQL

 

Database 를 활용한 Web page 구현을 위하여 MySQL DB를 제공하고 있습니다.

MySQL port 는 3306이며 MySQL Admin ID/PASSWORD 는 root/root 입니다.

 

Default DB로 "mysql" DB 가 default 로 작성되어 있습니다.
