Time Machine

Tjänsten Time Machine är en funktion för automatisk säkerhetskopiering och som finns i Mac OS X. Tjänsten upprätthåller kopian med Mac-data så att den ska motsvara uppdateringsläget i LG Nätverkslagringsenhet.

 

※ Tjänsten har stöd för Mac OS X version 10.5 Leopard eller senare.

[Webbinställning]

① Ange en mapp där kopian med Mac-data ska sparas. Ange AFP (Mac) som stödprotokoll i mappinställningen.

② Ange att Time Machine ska användas och välj mapp.

③ Tryck på verkställningsknappen

※ Om AFP-servern är inaktiverad på webben aktiveras den automatiskt när inställningar görs för Time Machine i Mac.

 

[Mac OS]

① Tryck på Systemmiljöinställningar > Time Machine

② Tryck på Ändra diskenhet, välj en mapp som har angivits på webben och tryck sedan på Använd som säkerhetskopiering.

③ När inloggningsfönstret visas anger du ID och lösenord samt trycker på Anslut.

④ Då slås Time Machine automatiskt ”på” och säkerhetskopiering påbörjas.

※ Om du trycker på knappen Alternativ kan du ange en mapp som inte behövs för säkerhetskopiering.
