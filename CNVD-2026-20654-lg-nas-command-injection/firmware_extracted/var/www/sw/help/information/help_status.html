Status

Status för nätverk, volym och externa enheter för LG Network Storage kan visas. För mera specifika detaljer eller för att utföra ändringar, om man klickar på symbolerna längstner kommer användaren att vidarebefordras till relevant hemsida.

① Information för Mac-adress, IP, Subnet Mask, Gateway, DNS-server, Ethernet Frame Size, länkhastighet, etc. kan visas.  

② Konfigurerad volymlista och information för användning/RAID-tillstånd, etc. kan visas.

③ All hårddiskinformation som är ansluten till LG Network Storage kan visas efter Bay-position.  

④ Informationen som tillhör Blu-ray-enheten som är ansluten till LG Network Storage kan visas.

⑤ Informationen som tillhör USB-enheten och minneskortet som är anslutet till LG Network Storage kan visas.  

⑥ Informationen som tillhör e-SATA-enheten som är ansluten till LG Network Storage kan visas.  

⑦ Tillstånd för användare som för närvarande är ansluten till LG Network Storage kan visas.(SMB , FTP)
