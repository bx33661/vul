Network

El menú del wizard asiste a la configuración de red de los artículos tales como el nombre de servidor, la dirección IP, la fecha y la hora, que abarcan la información básica de la red.

Cliente

① Designe un nombre del cliente del LG Network Storage. El nombre de servidor tiene un límite de 12 caracteres, éste puede ser una combinación de letras, de dígitos, de rayas y de guiones; los primeros caracteres sin embargo deben ser una letra o un número.

Ejemplo de un Nombre Correcto : LG-NAS, LGNAS-123

Ejemplo de un Nombre Incorrecto: LG_NAS, -LGNAS, 123-LG, LG-#, LG/

② Mecanografíe adentro la descripción del cliente. La descripción del cliente tiene un límite de 24 caracteres; ésta puede ser una combinación de letras, de dígitos, de rayas, de guiones y de espacios.

Esta explicación afecta solamente al cliente de Windows.

Interfaz

Se especifican las características del IP del interfaz de red. Durante la conexión del sistema, el cuidado debe ser tomados como restricciones pueden ser creadas.

Si el administrador del web ha asignado un IP o haya algún IP que quiera usar, elija ‘Configuración de IP Manual’. Designe cada valor del IP, Subnet-mask, gateway y DNS.

∙ Dirección de IP: la dirección del IP que desee usar.

∙ Subnet-mask: el subnet-mask que sea adequado en las condiciones de la web.

∙ Gateway: si no hay un gateway específico que desee usar o no haya un gateway básico, designe el valor igual a la dirección del IP.

∙ Dirección del servidor DNS básico: el servidor DNS sirve para intercambiar el nombre del dominio a la dirección del IP. Si este valor no se designa correctamente, alguno de las funciones no se activaran correctamente.

∙ Dirección del servidor DNS de asistencia: designe la dirección del servidor DNS de asistencia.

* Si no sabe los valores exactos es recomendado designar cada valor con la ayuda de un experto o administrador del web.

[Configuración automática del IP]

Si desee configurar el IP automáticamente, seleccione ‘Configuración automática del IP(DHCP)’. Este menú puede ser seleccionado si dentro del web está conectado un servidor(o módem externo) DHCP. Si la configuración automática DHCP es activado, toda conexión con el menú del web se desconectará. Puede verificar el nuevo IP atravéz del panel LCD o NAS detector. Con el uso de la configuración automática del IP(DHCP) el IP se renueva periódicamente.

Cuando la ‘Configuración automática del IP’ fue activado pero no existe ningún servidor DHCP, se asigna una dirección local como 169.254.XXX.XXX. Esto puede ser activado cuando el cable del internet se conecta directamente con el PC y la configuracion del PC es seleccionado como ‘configuración automática’.

[Configuración del marco de Ethernet]

Configure el tamaño de marco de Ethernet. Si el tamaño de marco es desconocido, fíjelo a 1500.

* Tamaño del marco de ethernet: Si el tamaño de marco de Ethernet es por lo menos 1500 gigabites, los archivos especificados se pueden enviar rápidamente y fácilmente. En este caso, el LG Network Storage solamente no cambia, pero así que haga los tamaños de marco de la PC y del ranurador casero/ ranurador/del eje/de interruptor. Si no el funcionamiento será reducido.

Grupo de trabajo /Dominio

Fije un grupo de trabajo y los dominios que la red de Windows apoye. Esto permitirá

el acceso a la carpeta compartida de la LG Network Storage en Windows. Además de esto, el servicio del dominio de LG Network Storage apoya un directorio activo de Windows, permitiendo la importación de la información de usuario existente, con fácilmente y velocidad.

① Seleccione el ‘Grupo de trabajo’ o el ` Dominio’ apropriado que considera el ambiente adonde el LG Network Storage funcionará.

② Cuando la selección del `Grupo de trabajo’, entre el nombre del grupo de trabajo requerido. O cuando la selección del ` Dominio ‘, entre el nombre de dominio, la identificación del administrador del dominio y la contraseña.

* Dominio: En el ambiente de usuario activo de directorio, los ajustes de la configuración del dominio no se deben crear en la carpeta local del usuario/del grupo, sino se deben creadas en la carpeta del usuario/del grupo del dominio. Cuando se crean las configuraciones del dominio, el administrador de red debe estar disponible para proporcionar ayuda, ya que el usuario debe tener acceso a toda la información referente al servidor de nombres. Si se entra la información incorrecta, la distribución y el uso del LG Network Storage serán limitados.

* En caso de infamiliaridad con el ‘grupo de trabajo/el dominio’, el uso de los valores prefijados es recomendado.
