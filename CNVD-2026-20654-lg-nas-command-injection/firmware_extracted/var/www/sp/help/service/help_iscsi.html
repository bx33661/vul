iSCSI

Esto permite al usuario utilizar la unidad Blu-ray / DVD del LG Network Storage como una unidad de CD. El servicio iSCSI de LG Network Storage permite a múltiples usuarios acceder y usar el sistema.

[Instalación del Iniciador iSCSI]

Para poder utilizar el iSCSI, el Iniciador del programa debe estar instalado en el ordenador.

A. Instalación del iniciador en un PC con Windows.

Para Windows XP, descargue el programa de instalación del siguiente sitio Microsoft.

☞ Sitio de web

http://www.microsoft.com/downloads/details.aspx?familyid=12cb3c1a-15d6-4585-b385-befd1319f825&displaylang=en

Para Windows Vista, el sistema operativo ya incluye un programa adicional y no se requiere instalación.

B. Instalación del iniciador en un PC con Linux.

Para Linux, el Iniciador puede instalarse automáticamente desde el sitio web. Para Ubuntu Linux, escriba

$ sudo apt-get install open-iscsi

y para fedora, introduzca

$ yum install open-iscsi

para instalar automáticamente el iniciador.

☞ Sitio de web

http://www.open-iscsi.org/

C. Instalación del iniciador en un Mac

Instale el iniciador iSCSI Globalsan. Esto puede ser descargado desde el “estudio de soluciones de red” en la página de inicio.

☞ Sitio de web

http://www.studionetworksolutions.com

[Sincronización de Servidor]

En la página web, haga clic en “Activar” y haga clic en “Apply”. Una vez que el iSCSI se activa, algunas funciones como la quema del web serán limitados.

[Conexión iSCSI]

A. Conexión en un PC con Windows

① Activar el iniciador iSCSI.

Para Windows Vista, vaya a “Panel de control -> Iniciador iSCSI “ y active el Iniciador. Para Windows XP, vaya al menú de Inicio y seleccione Iniciador iSCSI en la lista de programas.

Si un procedimiento de certificación obligatoria(CHAP) se ha creado en la configuración del web, la información solicitada deberá consignarse en la pantalla ‘General’, pulsando el botón Secreto.

② Encuentre el objetivo iSCSI (LG-NAS).

Haga clic en el ‘Descubre tab’ en la parte superior del programa Iniciador del iSCSI. Luego haga clic en el botón “Añadir” en la parte inferior. Entonces una nueva ventana para agregar Meta Portal (imagen inferior) aparecerá. Introduzca la dirección IP del destino(LG Network Storage).

Si el procedimiento de certificación obligatoria(CHAP) se fue configurado en el web, la información requerida debe ser ingresado pulsando el botón Avanzada.

③ Entre a la sesión

Vaya al ‘Targets tab’ de la parte superior del programa Iniciador del iSCSI. Si todos estos procedimientos fueron seguidos correctamente, el Iniciador del iSCSI encontrará y listará las informaciones del objetivo(LG-NAS). Seleccione el nombre del destino y pulse el botón “Iniciar sesión en...”. Y haga clic en “Aceptar” en la ventana emergente.

④ Verifique que el objetivo se ha conectado de la siguiente manera.

El objetivo puede ser controlado desde Administrador de dispositivos -> DVD / CD-ROM.

⑤ El ODD con NAS se puede acceder mediante el uso de herramientas tales como CyberLink Power2Go.

⑥ Salga de la sesión al terminar.

Vaya al ‘Targets tab’ en la parte superior del programa Iniciador del iSCSI. Luego, haga clic en el botón Detalles en la parte inferior.

Seleccione el nombre de destino y haga clic en “Cerrar sesión. . . “

※ Debido a problemas de compatibilidad entre Iniciador iSCSI y Windows Vista, el ODD con Windows Vista incorporado puede estar indisponible.

B. Conexión en un PC con Linux

① Activar el iniciador iSCSI. $ /etc/init.d/open-iscsi start

② Encuentre el destino iSCSI. Si la dirección IP del LG NAS(destino) es 192.168.10.2, el objetivo es: $ iscsiadm -m discovery -t sendtargets -p 192.168.10.2

Una vez que se encuentre el objetivo, ejecute el comando anterior, cual le mostrará el nombre del destino. El siguiente es un ejemplo: $ 192.168.10.2:3260,1 iqn.2009-01.com.lge:LG-NAS.123456

③ Entrar a la sesión. El comando para entrar a la sesión del destino superior es: $ iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 --login

④ Confirme la conexión utilizando el comando siguiente: $ cdrecord -scanbus

⑤ Herramientas de ODD como cdrecord puede ser usado para utilizar el ODD con NAR.

☞ Sitio de web

☞ http://cdrecord.berlios.de/private/cdrecord.html

⑥ Salga de la sesión al terminar. Use el comando siguiente: $ iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 --logout

[Conexión para CHAP certificación]

① Abra el archivo open-iscsi set-up “/etc/iscsi/iscsid.conf” y configure el CHAP certificación. Siga las instrucciones a continuación. (La contraseña del CHAP certificación debe coincidir con la contraseña creada para el servicio de iSCSI en la página web de LG Network Storage).

discovery.sendtargets.auth.authmethod = CHAP

discovery.sendtargets.auth.username = inAdmin

discovery.sendtargets.auth.password = password set up (Target Secret)

node.session.auth.authmethod = CHAP

node.session.auth.username = outAdmin

node.session.auth.password = password set up (Initiator Secret)

② Activar open-iscsi. $ /etc/init.d/open-iscsi start

Si el open-iscsi ya estaba activado, reinicie. $ /etc/init.d/open-iscsi restart

③ El resto de los procedimientos es igual al [Conexión en un PC con Linux]

C. Conexión con un Mac

① Active el iniciador iSCSI. Vaya a Preferencias del Sistema -> globalSAN iSCSI

② Encuentre el destino iSCSI. Si la dirección IP es 192.168.10.2, ver abajo.

Vaya a globalSAN iSCSI -> Portales y pulse “+” y escriba 192.168.10.2 y presione “Aceptar”

Si el procedimiento de certificación obligatoria(CHAP) se fue configurado en el web, la información requerida debe ser ingresado pulsando el botón Avanzada.

③ Entre a la sesión Vaya a globalSAN iSCSI -> objetivos, seleccione los destinatarios y haga clic en “Iniciar sesión en...”. Luego haga clic en “Connect”en la ventana emergente.

④ Confirme que el objetivo está conectado de la siguiente manera. Vaya a Utilidades -> Perfil de Sistema y compruebe que “iSCSI” aparezca en interconexión de “Grabación de disco”.

Herramientas tales como la Utilidad de Disco / buscador pueden ser usados para utilizar el ODD con NAS.

⑤ Salga de la sesión al terminar. Vaya a globalSAN iSCSI -> objetivos, seleccione los destinatarios y haga clic en “Cerrar sesión...”. Luego, haga clic en “Desconectar” en la ventana emergente.

Debido a que la conexión de red con la unidad Blu-ray del LG Network Storage permite a cualquier usuario conectado utilizar el programa, es importante que los demás usuarios no interrumpan. Por ejemplo, en el caso de que un usuario esté quemando los datos mediante Blue-ray, se recomienda evitar los comandos que puede interferir con el trabajo, tales como “abrir la bandeja”

Además, si la escritura / lectura de los datos del LG Network Storage está en marcha a través de la conexión de red, puede haber transferencias de datos dentro de la red y causar dificultad en transferencia de datos a través de iSCSI, lo que resulta en más lenta y limitada escritura / lectura.
