DDNS (DNS Dynamico)

Usando DDNS y la conexión del LG Network Storage externamente por nombre de Domain es posible.(Ejemplo : http://myname.lgnas.com , o ftp://myname.lgnas.com)

Para registrar y conectar la dirección de IP del servidor con en el caso de usar un IP fijo es posible, aunque el DDNS permite una conexión conveniente en un ambiente dinámico del IP, donde el IP cambia a tiempo. La variación de la dirección de IP se supervisa y se traza a un nombre de Domain en tiempo real. Por lo tanto, no es necesario el recordar la dirección IP, pues habrá una dirección fija. (e.g. myname.lgnas.com)

① Seleccione el `ENABLE (permitir)’ para DDNS.

② Entre el nombre del Domain que se utilizará.

③ Entre la contraseña.

* La contraseña es necesario para la re-registración del nombre del Domain, para la inicialización del sistema, reemplazo del LG Network Storage u otras razones. No olvide la contraseña.

④ Cliquee encendido el botón de Aplicar.

* Si se selecciona el ` DISABLED (No Permitir)’ después de que se coloque un nombre de Domain, el dominio anterior será quitado, y el nombre de Domain no se puede colocar así en otros dispositivos del LG Network Storage. La precaución debe ser tomada al fijar esto.

[UPnP]

Usando el ‘UpnP port forwarding’ se puede recibir directamente por LG Network Storage las solicitudes que entran por los modem esternos conectados con LG Network Storage. Para conectar desde el externo tras DDNS al LG Network Storage se necesita modificar las configuraciones para que las solicitudes que entran por los modem esternos sean transmitidos directamente al LG Network Storage.

① Verifique si la dirección del modem conectado al NAS se señala correctamente.

② Si la dirección del modem se señala correctamente, se puede verificar si la función ‘Port forwarding’ está activa.

③ Haga un clic en el botón ‘Aplicar’.

♣ Si el modem externo no apoya la función ‘UPnP port forwarding’ o si la función no es activada, la ‘UPnP port forwarding’ puede funcionar incorrectamente.
