DLNA(Digital Living Network Alliance)

DLNA, lo que significa Digital Living Network Alliance, permite un fácil acceso a los datos de multimedia como música, vídeo o imágenes por PC, disco duro o Televisión Digital a través de la red doméstica. EL DNLA se puede dividir en DMS(digital media server) que proporciona los datos de multimedia y DMP(digital media player) que los recive. Con el fin de utilizar plenamente la función DLNA, el producto debe ser certificado con DLNA. Este producto se adhiere al Digital Media Server (DMS) de la función estándar DLNA.

[Activar/Desactivar DNLA]

Con el fin de activar o desactivar el DLNA, siga los procedimientos seguientes Siga las instrucciones a continuación.

① Abra la página web de DLNA.

② La sección superior muestra el estado actual del DLNA. Para activar el Media Server (DMS), haga clic en “aplicar”.

③ La ruta de origen se refiere a la ubicación de los datos de multimedia que está guardado. Con el fin de utilizar los datos de multimedia a través de DLNA, se debe determinar la ubicación de los datos guardados. Los servicios DLNA sólo será aplicable a las carpetas con pre-establecido DLNA.

④ Presione el botón “Aplicar” para activar. Para desactivar, chequee en “desactivar” y presione “Aplicar”.

[Guardar los datos de multimedia en la ruta original]

Se puede traer, guardar y acceder a los datos de multimedia usando la red por LG Network Storage.

① Ejecute ‘Internet Explorer’.

② Copie los datos en la carpeta service\DLNA.

♣ Nota

① No elimine la ruta original(service\DLNA). No podrá seguir los procedimientos relacionados con los datos de multimedia.

② Use solamente los archivos con los formatos soportados. Los archivos con formatos que no son soportados no se reproducen.

③ Los aparatos como un televisor normal que no soportan Digital Media Player, no reproducerán correctamente los archivos aunque sean soportados por LG Network Storage.

[Reproducir datos de multimedia por DLNA]

Usar DNLA en un PC con Microsoft® Windows7®.

① Seleccione ‘Añadir un dispositivo’ en Panel de control> Hardware y sonido.

② Si la búsqueda del LG Network Storage se termina, presione ‘Seguir’.

③ Opere Windows Media Center o Windows Media Player.

④ Seleccione en la Librería(Library) LG Media Server y disfrute los datos de multimedia en LG Network Storage.

♣ Nota

∙ Para el uso del Windows Media® Player 11, tenga referencia a ‘Ayudas’ del Windows Media® Player 11.

∙ De acuerdo con cada PC, puede haver instalados independientes servidores para DLNA. Tenga referencia al manual de cada PC para más información.

[Usar DNLA en un PS3™.]

Si enciende el PS3™, se procede una búsqueda automática de servidores para DLNS señalando los resultados con iconos (Fotos) / (Músicas) / (Videos).

① Seleccione el servidor del DLNS para conectar en el menú con los iconos (Fotos) / (Músicas) / (Videos). Se señala todos los datos que pueden ser reproducidos en PS3™.

② Seleccione el dato que quiera reproducir.

♣ Nota

∙ El PS3™ debe estar conectado al web. Para ver la configuración del web, tenga referencia al [Configuración del Internet] en Establecer > Establecer la Red.

∙ En caso de usar el modo DHCP en la configuración de la dirección IP, haga una nueva búsqueda del servidor DLNA.

∙ El icono del servidor DLNA aparece solamente si la [Conexión del Servidor de Multimedia] en Establecer > Establecer la Red es activado.

∙ El nombre de la carpeta varía por cada servidor de DLNA. (El valor básico es LG-NAS.)

∙ Algunos archivos no pueden ser reproducidos en ciertos aparatos correctamente.

∙ Los datos con licencia no pueden ser reproducidos.

∙ Hay casos donde se adhiere una ‘*’ en los datos que no son de servidores DLNA. Algunos de estos datos no son reproducidos en PS3™. Algunos de estos datos que son reproducidos en PS3™ no son reproducidos en otros aparatos.

[Buscar un servidor DLNA manualmente en PS3™.]

Se puede re-buscar un servidor DLNA dentro de la misma red. Esto es para casos de que el servidor no sea reconocido automáticamente por PS3™.

En los iconos (Fotos) / (Músicas) / (Videos), seleccione (Búsqueda del Servidor de Multimedia). Cuando se señale el resultado, vuelva al menú principal y chequee la lista de servidores DLNA.

♣ Nota

El icono (Búsqueda del Servidor de Multimedia) aparece solamente si la [Conexión del Servidor de Multimedia] en (Establecer) (Establecer la Red) es activado.

[Usar DNLA en un Marco Fotográfico Digital(Digital Picture Frame).]

① Active la función DLNA en LG Network Storage.

② Instale los drivers y confure el Marco Fotográfico Digital de acuerdo con el manual de instrucciones.

③ Proceda una búsqueda para encontrar LG Network Storage en el Marco Fotográfico Digital.

④ Conecte el LG Network Storage con el Marco Fotográfico Digital.

⑤ Disfrute los fotos en el Marco Fotográfico Digital.

♣ Nota

∙ Tenga referencia al manual de instrucciones para verificar los formatos soportados, modo de reproducción, etc.

∙ Para la configuración de la conexión del LG Network Storage con el Marco Fotográfico Digital, tenga referencia al manual DMA del Marco Fotográfico Digital.

[Uso del dispositivo AV(Audio-Video) con DLNA]

Active la función DLNA conectado por el web para reproducir los datos de multimedia. Las configuraciones varían por cada dispositivo. Tenga referencia a los manuales de cada dispositivo.
