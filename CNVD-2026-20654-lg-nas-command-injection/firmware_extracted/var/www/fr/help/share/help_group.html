Groupe

 

Les groups actuellement enregistrés sont affichés. Les groupes peuvent être créés ou supprimés comme les utilisateurs enregistrés dans les groupes.

 

[Créer un Nouveau Groupe]

① Cliquez sur le bouton ‘Créer Nouveau Groupe’.

 

② Entrez le nom du groupe.

 

③ Entrez la description du groupe.

 

④ Cochez l’utilisateur à ajouter dans le groupe. Pour supprimer un utilisateur du groupe, désélectionnez l’utilisateur en cliquant à nouveau la case à cocher.

 

⑤ Lorsque la sélection d’utilisateur est terminée, cliquez sur le bouton ‘Sauvegarder’ pour créer le groupe.

 

[Editer Groupes]

Cliquez sur le lien ‘Nom de groupe’ dans la liste des groupes enregistrés, et vous pouvez modifiez les attributs de groupe.
