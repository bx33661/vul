Das Speichern von Daten auf dem LG NAS mit Hilfe des Blu-ray-Laufwerks ermöglicht die Sicherung und Wiederherstellung von Dateien eines Datenträgers..

  • Geplante Backups können für die Backup-Liste erstellt oder aus ihr entfernt und gelöscht werden.
  • Die geplanten Backups werden in einem Ordner abgelegt. Wenn ein geplantes Backup erstellt wird, müssen Informationen zum Backupordner, zum Intervall und zu den Eigenschaften der Sicherungsdateien angegeben werden. Mehrere geplante Backups können auf einer Backup-Disc gespeichert werden.
  • Für die erste Datensicherung muss ein leerer oder formatierter Datenträger verwendet werden. Zur Initialisierung muss die Schaltfläche “Programmstart“ im Wiederherstellungs-Menü verwendet werden.
  • Folgende Datenträger können für geplante Backups verwendet werden: BD-RE, BD-R, DVD-RAM, DVD+/-RW.
  • Neues Backup erstellen
  • ① Klicken Sie auf “Erstellen“, um einen geplanten Backup-Task zu erstellen./li>
  • ② Geben Sie einen Namen ein.
  • ③ Geben Sie eine inhaltliche Beschreibung ein.
  • ④ Wählen Sie einen Ordner im LG NAS, von dem aus das Backup erfolgen soll.
  • ⑤ Wählen Sie den Intervall des Backup-Zyklus aus: täglich, wöchentlich, monatlich.
  • Legen Sie für den monatlichen Backup-Zyklus ein entsprechendes Datum fest. Legen Sie für den wöchentlichen Backup-Zyklus einen entsprechenden Tag fest.
  • ⑥ Legen Sie einen Zeitpunkt für die Datensicherung fest.
  • ⑦ Wählen Sie die Backup-Methode.
  • Die Datensicherung wird durch das Backup der Dateieinheit konfiguriert. Hierbei stehen inkrementelle Sicherungen sowie eine vollständige Sicherung zur Verfügung. Bei der Ausführung der Datensicherung wird ein neuer Ordner erstellt, in dem die Ordner und die dem Ordner zugeteilten Dateien gespeichert werden. Dieser wird wie folgt benannt: ‘yyyymmddhhmmss’.
  • Wenn eine inkrementelle Sicherung gewählt wird, werden nur die Dateien gesichert, die zuvor verändert wurden.
  • ⑧ Um die erweiterten Einstellungen des geplanten Backups zu aktivieren, klicken Sie auf die Schaltfläche “Öffnen“ in der Tabelle der erweiterten Einstellungen.
  • ⑨ Die Dateiendungen der aktiven Dateien können für die Datensicherung festgelegt werden.
  • Wenn die Kontrollkästchen für ‘Bild Abk.’ und ‘Dokument Abk.’ markiert sind, werden die ausgewählten Bilder- und Text-Dateien gesichert. Wenn nichts festgelegt wurde, werden automatisch alle Dateien gesichert.
  • ⑩ Die Dateiendungen von Dateien, die nicht gesichert werden sollen, können festgelegt werden.
  • Eine Sicherung von Dateien mit Dateiendungen wie z.B. *.bak, *.tmp ist nicht erforderlich.
  • ⑪ Klicken Sie auf “Speichern“, um die geplanten Backups zu speichern.
  • ⑫ Der Datensicherungsprozess wird sofort gestartet, wenn man ein Element aus der Backup-Liste anwähltt und dann auf die Schaltfläche “Sicherung“ klickt.
  • Geplante Backups bearbeiten
  • Nachdem Sie das gewünschte Backup aus der Liste ausgewählt haben, klicken Sie auf “Ändern“, um das Element zu bearbeiten., oder klicken Sie auf den Namen, um bestimmte Eigenschaften zu ändern.
  • Geplante Backups löschen
  • Nachdem Sie das gewünschten Backup aus der Liste ausgewählt haben, klicken Sie auf “Löschen“, um das Element zu entfernen.
  • Wiederherstellung
  • Bestimmte Dateien oder Ordner können im LG NAS mit Hilfe der Backup-Disc wieder hergestellt werden. Feste Ordner(/Share/Restore) können wieder hergestellt werden. Bei einer Wiederherstellung wird das Standarddatum und die Standardzeit im Ordnernamen eingefügt und der Ordner wird wieder hergestellt. Zum Beispiel: “081027_162040”.
  • Wiederherstellung kann auf Ordner-, oder Datei-Ebene erfolgen.
  • [Wiederherstellung von Ordnern]
  • ① Wählen Sie im linken Fenster die Ordner aus, die wieder hergestellt werden sollen.
  • ② Klicken Sie auf die Schaltfläche “Wiederherstellen“, um den Prozess zu starten.
  • [Wiederherstellung von Dateien]
  • ① Wählen Sie im rechten Fenster die Dateien aus, die wieder hergestellt werden sollen.
  • ② Klicken Sie auf die Schaltfläche “Wiederherstellen“, um den Prozess zu starten.
  • Tipp 1) Wenn aufgrund von verschiedenen Sicherungszeitpunkten mehrere Versionen einer Datei vorliegen, können die aktuellste Datei oder auch alle Dateien an- oder abgewählt werden.
  • Tipp 2) Im Wiederherstellungs-Fenster auf der rechten Seite kann man nach Dateien suchen die Wiederhergestellt worden sind. Geben Sie den Namen der gewünschten Datei in das Suchfeld ein. Der Suchvorgang wird durch Klicken auf die Schaltfläche “Suchen“ ausgeführt.
