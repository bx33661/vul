iSCSI

 

Dette tillater brukeren å bruke LG Nettverkslagring Blue-ray/DVD stasjonen som en CD-stasjon. LG Nettverkslagring iSCSI-tjenesten tillater flere brukerens innlogging og bruk.

 

[iSCSI Initiativtaker Installasjon]

 

For å bruke iSCSI, initiativtakeren programmet må installeres på datamaskinen.

 

A.          Initiativtaker Installasjon på en Windows PC

 

For Windows XP, laste ned installasjonsprogrammet fra nedenfor Microsofts nettside.

Nettside

 

http://www.microsoft.com/downloads/details.aspx?familyid=12cb3c1a-15d6-4585-b385-befd1319f825&displaylang=en For Windows Vista, operativsystemet allerede har et program og ingen ekstra installasjon er nødvendig.

 

B.          Initiativtaker Installasjon på en Linux PC

 

For Linux, Initiativtaker kan installeres automatisk fra nettstedet. For Ubuntu Linux, skriver inn

$ sudo apt-get install open-iscsi

 og for Fedora, skriver inn

$ yum install open-iscsi

 

for å automatisk installere initiativtaker.

Nettside http://www.open-iscsi.org/

 

C.          Initiativtaker Installasjon på en Mac

 

Installer globalsan iSCSI initiativtakeren. Denne kan lastes ned fra “studio network solutions” nettside.

 

Nettside

 

http://www.studionetworksolutions.com

 

 

[Server Synkronisering]

 

På nettsiden, klikke på "Enable" (aktiver) og deretter klikke på "Apply". Når iSCSI er aktivert, visse funksjoner som web forbrenne vil være begrenset.

 

[iSCSI Tilkobling]

 

A.          Tilkobling på en Windows PC

 

①    Aktiver iSCSI initiativtakeren.

For Windows Vista, gå til “Control panel → iSCSI Initiator” og aktivere initiativtakeren. For Windows XP, gå til Start-menyen og velg iSCSI initiativtaker fra programmet listen.

Hvis en obligatorisk sertifisering (CHAP) prosedyren har vært satt opp i nettet innstilling, skriv inn nødvendig informasjon nedenfor General (generelt) ved å trykke på "Secret" knappen.

 

②    Finn iSCSI mål (LG-NAS).

 

Klikke på "Discovery" kategorien på toppen av iSCSI initiativtaker programmet. Deretter klikke på "Add" knappen på bunnen. Deretter, et nytt vindu " Add Target Portal" (legg målportalen) (bildet under) bør vises. Skriv inn målet (LG Nettverkslagring) IP-adressen.

 

Hvis en obligatorisk sertifisering (CHAP) prosedyren har vært satt opp i nettet innstillingen, skriv inn den nødvendige informasjonen ved å trykke på "Advanced" (avansert) knappen i vinduet ovenfor.

 

③    Logg inn.

 

Gå til Målsettinger kategorien på toppen av iSCSI initiativtaker programmet. Hvis alle de ovennevnte prosedyrer har blitt fulgt riktig, iSCSI initiativtaker vil finne og liste opp informasjon om målet (LG-NAS). Velg det relevant målnavnet og trykke på "Log On. . . " og klikke på "OK" fra vinduet.

 

④    Se hvis målet har vært koblet slik.

 

Målet kan kontrolleres ved å gå til ”Device administrator” → ”DVD/CD-ROM drive” (enhet administrator → DVD / CD-ROM-stasjon).

 

⑤    NAS innebygd ODD kan nås ved bruk av verktøy som CyberLink Power2Go.

 

⑥    Logg ut når ferdig.

Gå til Målsettinger kategorien på toppen av iSCSI initiativtaker programmet. Deretter klikke på "Details" (detaljer) knappen på bunnen.

 

Velg relevant Målsetting Navnet og klikke på “Log Off. . . “ (logg ut).

 

* På grunn av kompatibilitetsproblemer mellom iSCSI initiativtakeren og Windows Vista, Windows Vista innebygde ODD rekord funksjoner, "mastered" eller "live file system" er kanskje ikke tilgjengelige.

 

B.          Tilkobling på en Linux PC

 

①    Aktivere iSCSI initiativtaker.

 

$     /etc/init.d/open-iscsi start

 

②    Finn iSCSI målet. Hvis LG NAS (mål)’s IP adresse er 192.168.10.2, målet er:

 

$     iscsiadm -m discovery -t sendtargets -p 192.168.10.2

 

Når målet er funnet, effektuere overfor kommandoen, som vil vise målet navnet. Det følgende er et eksempel:

 

$     192.168.10.2:3260,1 iqn.2009-01.com.lge:LG-NAS.123456

 

③    Log in. Log-in command for the above målnavnet er:

 

$     iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 --login

 

④    Bekreft måltilkobling ved hjelp av nedenfor kommandoen.

 

$ cdrecord -scanbus

 

⑤    ODD verktøy som cdrecord kan brukes til å utnytte NAS innbygde ODD. Nettside

 

http://cdrecord.berlios.de/private/cdrecord.html

 

⑥    Logg ut når ferdig.  Bruk følgende kommandoen:

 

$ iscsiadm --mode node --targetname iqn.2009-01.com.lge: LG-NAS.123456 --portal 192.168.10.2:3260 –-logout

 

[Tilkobling for CHAP sertifisering]

 

①    Åpne den åpen - iSCSI sette opp fil “/etc/iscsi/iscsid.conf” og sette opp CHAP sertifisering. Følg instruksjonene nedenfor. (CHAP sertifikatet passordet må samsvare med passordet satt opp for iSCSI tjenesten på LG Nettverkslagring nettside.)

 

discovery.sendtargets.auth.authmethod = CHAP discovery.sendtargets.auth.username = inAdmin discovery.sendtargets.auth.password = password set up (Target Secret)

 

node.session.auth.authmethod = CHAP node.session.auth.username = outAdmin node.session.auth.password = password set up (Initiator Secret)

 

②    Activate open-iscsi.

 

$ /etc/init.d/open-iscsi start

 

If the open-iscsi was already activated, restart.

 

$ /etc/init.d/open-iscsi restart

 

③    Resten av rutinene er de same som for [Tilkobling på en Linux PC].

http://manpages.ubuntu.com/manpages/hardy/man8/iscsiadm.8.html http://wiki.debian.org/iSCSI/open-iscsi

 

C.          Tilkobling på en Mac

 

①    Aktivere iSCSI initiativtaker.

Gå til "System Preferences" (systemvalg) -> globalSAN iSCSI

 

②    Finn iSCSI målet. Hvis IP-adressen er 192.168.10.2, se nedenfor.

 

Gå til  "globalSAN iSCSI" -> "Portals" og trykke på “+” og skriv inn 192.168.10.2 og trykke på  “OK”.

 

Hvis en obligatorisk sertifisering (CHAP) prosedyren har vært satt opp i nettet innstillingen, skriver inn den nødvendige informasjonen ved å trykke på "Advanced" (avansert) knappen i ovenfor vinduet.

 

③    Logg inn.

 

Gå til ”globalSAN iSCSI” -> ”Targets”, velger det relevant målnavnet og klikker på “Log On. . . .” og deretter “Connect” på vinduet.

 

④    Bekreft at målet er koblet som følger.

 

Gå til ”Utilities” (verktøy) -> ”System Profil” og sjekk at “iSCSI” viser under “Disc Burning” (diskforbrenne).

 

Verktøy som ”Disk Utility” / ”Finder”` kan brukes til å utnytte NAS innebygde ODD .

 

⑤    Logg ut når ferdig.

 

Gå til ”globalSAN iSCSI” -> ”Targets”, velg det relevant målnavnet og klikk på “Log Off. . . .” of deretter “Disconnect” på pop-up vindu.

 

* Merknader

 

Fordi LG Nettverkslagring Blue-ray stasjon nettverkstilkobling tillater noen påloggede brukeren å bruke programmet, det et viktig at andre brukere ikke er avbrutt. For eksempel, i tilfelle at andre brukere forbrenner data ved hjelp av Blue-ray stasjon, det er anbefalt å unngå kommandoer som kan forstyrre med arbeidet, slik som "åpne skuffen".

 

I tillegg, hvis data skriving / lesing på LG Nettverkslagring pågår gjennom nettverksstasjon forbindelse, der kan være betydelige dataoverføringer innen i nettverket og kan gjøre det vanskelig å overføre data gjennom iSCSI, så det resulterer i langsom og begrensede skriving / lesing hastighet per disk .
